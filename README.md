# 💬 Mobile Chat App (React Native + Node.js)

A full-stack real-time chat application built with **React Native (frontend)** and **Node.js + Express + MongoDB (backend)**.  
It supports authentication, private conversations, real-time messaging with Socket.IO, typing indicators, and message delivery/read status.

---

## 🚀 Features

- 🔐 **Authentication** — Register & Login using JWT
- 👥 **User List** — Browse and select users to chat
- 💬 **Real-Time Messaging** — Powered by Socket.IO
- ✍️ **Typing Indicator** — See when the other user is typing
- 📩 **Delivered & Read Receipts**
- 🎨 **Attractive UI** — Responsive sender/receiver message bubbles
- 📱 **React Native Frontend** — Works on Android & iOS
- 🗄️ **Node.js Backend** — REST + Socket.IO server with MongoDB

---

## 🛠️ Tech Stack

**Frontend (React Native):**
- React Native
- AsyncStorage
- FlatList / TouchableOpacity
- Axios (API calls)

**Backend (Node.js):**
- Node.js + Express
- MongoDB + Mongoose
- Socket.IO
- JWT Authentication
